# Painted adventure assets

Option 01 was selected for the playable game. These source PNGs were generated with the built-in image tool using `public/art-studies/painted-adventure.webp` as the style reference. Export with `node scripts/prepare-painted-art.mjs`; only the resulting `public/painted/*.webp` files ship to the browser. Preserve alpha in the character sheets.

The exporter splits material quadrants and character columns, trims transparent padding, and compresses local WebP assets. It does not generate or redraw artwork. Colin has standing and three walk poses; adult passengers use standing illustrations with subtle movement while walking.

## Transparency

The retained RGBA sprite sheets came from this built-in image edit prompt:

Use case: background-extraction. Edit this sprite sheet ONLY to remove the entire gray and white checkerboard background. The checkerboard is currently baked into the RGB image and is a defect. Deliver a genuinely transparent RGBA PNG with alpha=0 outside the character silhouettes, including the spaces between arms and body, between legs, and around the hair. Preserve every painted character exactly: same poses, colors, details, feet, size, column positions and overall canvas dimensions. No shadow, no white/gray/color background, no checkerboard at all. This file must composite directly over a game background using its alpha channel. Do not redraw the characters. TRANSPARENT BACKGROUND.

Later passenger cleanup attempts returned opaque images and were discarded. The exporter rejects sheets without alpha; the retained versions were checked against the game walls.
