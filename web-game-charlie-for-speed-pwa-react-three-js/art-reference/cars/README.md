# NFS III PC car references

The updated models are shown in [model-overview.jpg](model-overview.jpg); [model-notes.md](model-notes.md) records the details used for each car. The additional Countach, Diablo SV and CLK-GTR pass is shown in [favorites-overview.jpg](favorites-overview.jpg), with its references and changes in [favorites-notes.md](favorites-notes.md).

Open [index.html](index.html) to browse the downloaded pictures for all 19 cars in the supplied [PC roster](https://nfs.fandom.com/wiki/Need_for_Speed_III:_Hot_Pursuit/Cars_(PC)).

- `nfs3/`: the 19 racer pictures from the individual car pages' galleries, labelled **Need for Speed III: Hot Pursuit (PC)**.
- `nfs3/nfs3/`: nine extra pictures supplied by the user for the three favorites; these include other NFS releases. See [favorites-notes.md](favorites-notes.md) for their filenames.
- `nfs3/police/`: the three additional PC police variants found in those galleries (Corvette, El Niño and Diablo SV).
- `sources.json`: car pages, image pages, original image URLs, download URLs, dimensions, file sizes and SHA-256 checksums for every picture.
- `contact-sheet.jpg`: an overview of the 19 racer pictures.
- `user-roster.png`: the original screenshot supplied in the chat.

Downloaded on 25 October 2026 using Fandom's public MediaWiki API to select the gallery files and its `images.wikia.com` image host to retrieve them. All 22 downloaded images are 1920 × 1080 pixels. The host returns WebP images, so the local files use `.webp` extensions. That download contains no thumbnails, PlayStation pictures or pictures from other NFS games. The separate user-supplied favorites folder includes other releases, as listed above.

The downloaded images are reference material from EA's Need for Speed III, obtained through the Need for Speed Wiki. The supplementary pictures were supplied by the user. They are separate from the game's procedural car models and are not imported into the game or its offline asset cache. Check the linked image pages for their source and rights information.
