# Charlie for Speed

A 3D sports-car racing game built with React, Three.js and Vite, delivered as a PWA.

## Status

Fresh project base: an offline-capable PWA shell with a title screen. Racing gameplay is planned in [PLAN.md](PLAN.md).

## Commands

```bash
npm ci
npm start        # http://127.0.0.1:4014
npm run check    # Biome
npm run build    # TypeScript + production build
npm test         # Playwright against preview on 4015
```

Set `VITE_BASE_PATH=/sub/path/` to build for a hosting subpath.
